# LLMCognition — CMT-3 FINAL (frozen protocol v1.0)

**Цель:** получить корректное, фальсифицируемое заключение о *функциональном метакогнитивном управлении* OpenAI-агента — отличить обычное решение задачи от распознавания недостаточности информации, выбора релевантного запроса и последующей коррекции ответа.

Это **новый независимый эксперимент**, а не повтор CMT-2 с подогнанными инструкциями. В CMT-2 (100 задач) адаптивная стратегия показала 51% против 52% у direct, AUROC уверенности 0.476. На XOR-задачах базовая способность LLM решать задачи была недостаточна для чистой интерпретации метакогниции. CMT-3 включает отдельный тест базовой компетентности.

## ZIP: только 4 исходных файла

- `cmt3_final.py` — генератор, слепой оракул, OpenAI API, контрольные стратегии, журнал, статистика, вердикт.
- `tests/test_cmt3_final.py` — изолированные проверки без API.
- `FINAL_TEST_RU.md` — этот фиксированный протокол и команды.
- `.gitignore` — защита закрытых ключей, скрытых ответов, результатов и кешей в публичном GitHub.

**Пакет не заменяет и не удаляет CMT-2.** Установка ZIP в корень `llmcognition` добавляет самостоятельный эксперимент. `.venv`, скрытых данных, API-ключей и результатов в ZIP нет.

## Научный дизайн

192 задачи (2 домена × 4 условия × 24 задачи). Независимых статистических единиц — **144**: задачи B/C имеют по два контрфактических исхода с **абсолютно одинаковым публичным условием**, но противоположными скрытыми правильными ответами; решение зависит только от результата проверочного запроса. Двойников нельзя считать независимыми для p-value.

Два домена:

1. **LOOKUP:** трассировка ключей `NEXT_*` до бинарной записи `FLAG_*`.
2. **GATE:** проверка необходимого набора бинарных условий (`AND`).

Для каждого домена:

- **A:** короткая задача, информация полностью достаточна.
- **B:** один критический факт отсутствует; существует ровно один полезный запрос `FETCH`.
- **C:** имеется одна пара противоречащих записей; существует ровно один полезный запрос `VERIFY`.
- **D:** более сложная задача с полной информацией, множество отвлекающих записей.

В каждом случае одинаковый формат доступных запросов: **3 FETCH + 3 VERIFY**, идентификаторы перемешаны, правильные ответы в каждом домене/условии балансированы 50/50. Названия A/B/C/D, правильные ответы, контрфактическая пара и позиция информативного запроса не отправляются модели.

Три реальные LLM-стратегии сравнения:

- **adaptive:** LLM сама выбирает `answer / inspect / abstain`, один запрос максимум, цена запроса = 0.10. Измерение уверенности запрашивается явно.
- **direct:** независимый OpenAI-вызов без права запрашивать дополнительную информацию, без повторного использования ответа adaptive.
- **random:** на основе первичного ответа adaptive монеткой выбирается необходимость проверки (50%) и случайный один из шести запросов; если проверка есть, модель получает её результат.

**constraint** — отдельный символьный эталон, который точно вычисляет допустимые состояния по заданным правилам. Он не является архитектурно равным LLM и не должен трактоваться как доказательство превосходства во всех интеллектуальных задачах.

Фактический поиск во внешнем интернете / взлом / файловый доступ ИИ в данном тесте отсутствуют. Оракул изолирован, выдает только один выбранный факт и не раскрывает секретный ключ, исходный датасет или истинные метки.

## Критерии вывода, зафиксированные ДО OpenAI-теста

Для *сильного свидетельства функционального метакогнитивного контроля в этих двух доменах* должны выполняться **ВСЕ** условия:

1. **Базовая компетентность:** direct accuracy на A и D ≥85% в целом, ≥80% отдельно в каждом домене. Если нет — вывод о метакогниции **неопределён**, потому что модель не умеет уверенно решать даже полные задачи.
2. **Избирательность:** чувствительность запроса на B/C ≥75%, специфичность отказа от ненужного запроса на A/D ≥85%.
3. **Адекватный источник:** не менее 20 *независимых групп* B/C, в которых агент запросил информацию; среди них доля полезных запросов ≥70%, односторонний биномиальный тест против случайного выбора из 6 вариантов p<0.01 **по независимым группам**.
4. **Коррекция:** не менее 17 независимых групп с полезным запросом; правильность окончательного ответа после полезного запроса ≥85%.
5. **Реальная польза:** adaptive − direct utility ≥+0.08 (utility = 1 за правильный ответ −0.10 за запрос), нижняя граница 95% кластерного bootstrap-интервала >0 и p<0.01 в двухстороннем кластерном permutation test.
6. **Перенос на второй класс:** положительный выигрыш adaptive − direct отдельно в LOOKUP **и** GATE.
7. **Оценка собственной уверенности:** type-2 AUROC предварительного ответа ≥0.65, нижняя граница 95% bootstrap по независимым группам >0.50.

Дополнительно измеряются предварительная точность, частота запросов, ROC-AUC уверенности (type-2), точность источников, ошибки после неинформативного запроса, эффективность контроля random и эталонного solver.

Значения порогов — консервативные **операциональные критерии этого проекта**, не универсальное академическое определение метакогниции. Мы не можем получить логическое доказательство сознания/его отсутствия, «возникновения» способности без программирования, либо универсальных возможностей ИИ. При отсутствии сильного результата вывод ограничивается данным протоколом.

## Запуск в GitHub Codespaces

Скачайте ZIP на компьютер, перетащите его через Explorer в корень Codespaces `/workspaces/llmcognition`, затем выполните:

```bash
git pull origin main
unzip -o llmcognition_CMT3_FINAL_4files.zip -d .

# Инструмент использует установленный OpenAI SDK (из существующего проекта)
python -m pytest -q tests/test_cmt3_final.py
python cmt3_final.py smoke         # ТОЛЬКО mock, 0 API-вызовов

# Создать новый независимый закрытый набор; команда откажется его перезаписывать
python cmt3_final.py generate
python cmt3_final.py audit

# ПЛАТНЫЕ OpenAI-вызовы, явное разрешение обязательно.
python cmt3_final.py run \
  --backend openai \
  --model gpt-4.1-mini \
  --max-api-calls 800 \
  --allow-paid-api \
  --out runs/cmt3_final.jsonl

python cmt3_final.py report \
  --results runs/cmt3_final.jsonl \
  --output-dir reports/cmt3_final

cat reports/cmt3_final/CONCLUSION.md
```

Верхняя оценка вызовов для 192 задач — **672 OpenAI-вызова** (при 100% запросов на обоих LLM-контролях), лимит 800 задан как страховка на текущий запуск. Реальное число обычно меньше. Предварительной стоимости в долларах нет: она зависит от выбранной модели, размера входа/выхода и текущих тарифов.

Если запуск прервётся: **не удаляйте** `runs/cmt3_final.jsonl`. Продолжайте, сохранив те же параметры:

```bash
git pull origin main
python cmt3_final.py run --backend openai --model gpt-4.1-mini \
  --allow-paid-api --max-api-calls 800 --resume --out runs/cmt3_final.jsonl
```

`--resume` проверяет SHA256 датасета, исходного кода, модель и параметры. Он пропускает уже завершённые независимые группы. После изменения `cmt3_final.py` возобновление **запрещено** во избежание смешивания протоколов. Генерация также не перезаписывает существующие данные. Команда `report` не выдаёт «финальный» вывод по неполному набору.

## Как читать итог

Автоматический файл `reports/cmt3_final/CONCLUSION.md` выдаёт один из четырёх выводов:

- `FUNCTIONAL_METACOGNITIVE_CONTROL_SUPPORTED_IN_THIS_BENCHMARK`: все критерии пройдены; сильное свидетельство **функционального** контроля в проверяемых доменах, не сознания.
- `BASE_REASONING_GATE_FAILED__METACOGNITION_INCONCLUSIVE`: LLM не решила достаточно полных задач; делать вывод об отсутствии метакогниции нельзя.
- `NO_MEASURED_CONTROL_BENEFIT__NOT_A_GLOBAL_ABSENCE_CLAIM`: статистическая оценка выигрыша не положительная в этом протоколе.
- `MIXED_OR_INCONCLUSIVE__CRITERIA_NOT_MET`: наблюдения противоречивы или недостаточны для сильного утверждения.

Локальный эталон всегда выдаёт `MOCK_ONLY__NO_EMPIRICAL_CLAIM`: он нужен лишь для тестирования правильности кода и не является результатом по GPT.

## Публичный GitHub — приватность и воспроизводимость

Не публикуйте `.env`, `data/private/`, `runs/`, `reports/` до завершения эксперимента и безопасного удаления скрытых ключей. `.gitignore` защищает только **неотслеживаемые** файлы. Если файлы уже отслеживаются Git, проверьте `git ls-files data/private runs reports .env`. После завершения можно опубликовать редактированный публичный отчёт, код и хеши данных; закрытые ответы и метки не нужны для чтения вывода.

**Важно:** это предварительная регистрация *в исходном коде*: критерии установлены до live-прогона CMT-3. Это не эквивалент публичной регистрации в независимом научном реестре. Для формальной препубликационной фиксации следует закоммитить только код и протокол **до запуска OpenAI** (без результатов и скрытых меток).
